# SXM 三角主设计回归测试清单

版本：v1.3 工作版，2026-11-11。当前设计依据：[SXM设计与参数化方案v0.24](sxm设计与参数化方案.md)。

本轮执行入口见[裁剪回归](../sim/sxm_prune/README.md)：保留功能与修改前RTL逐拍对照，并复用原已通过golden；删除功能转为拒绝测试，不改写历史成功记录。不运行综合，以下原物理结果只属于原快照。

本页保留分层验收门槛，同时记录历史执行进度；**部分子集通过不等于整行关闭**。LPU32主架构固定10槽＋MEM适配外壳，T2/T8为3/36槽；支持BF16/FP32，保留矩阵ROW→ROW/BLOCK8与VECTOR ROW→ROW。独立广播及整块输入已退出产品范围。VXM40拍不再作为SXM内部整改项目。旧报告的PASS仅按其源码和接口身份引用。

## 1. 统一测试边界

### 1.1 DUT分层

| 测试层 | 必须实例化什么 | 可以由fixture提供什么 |
|---|---|---|
| 核心单测 | 真正的新SXM核心/兼容壳 | 合法展开指令、MXM边界样式输入、明确能力的宽sink；只能证明SXM边界 |
| 外壳单测 | 可综合WriteTap排程/完成监视外壳；无完整块payload寄存器 | 逐拍bank服务模型，但必须按真实MEM命令波、端口和SRF位置建模 |
| 主集成回归 | 新SXM＋MEM适配外壳＋继承的真实MEM/SRF | 指令级展开源、输入样本、只观察不代替数据面的scoreboard |
| 最新FU集成 | 最新main MXM＋主集成，后续真实MEM Read→最新VXM | 公开权重/激活/指令；不能强写ACC、collector或MEM内部数组 |
| 物理 | 三档完整SXM、外壳、合体分别OOC | 同器件/时钟/综合策略；不得固定数据输入或丢弃输出裁剪逻辑 |

MEM适配外壳组合打包宽块到已有SRF，按多bank条带组织segment，使用原生WriteTap错拍排程；地址/私有控制/完成计数有寄存器，完整块payload副本为0 B。**测试台不能先把宽P结果重排成MEM能接的流，再称外壳集成通过。** scoreboard可以按逻辑坐标重建golden，但真实Read→VXM也必须能按实际命令拿到正确布局。

既有lpu_sxm_srf_adapter是无状态接线，不等同于本次已实现的MEM排程外壳。单拍总能接收的宽sink保留作单测，不作为L4验收者。

### 1.2 每次运行必须保留

- 代码SHA及dirty文件hash、工具版本、完整命令、T/格式/方向/几何、MEM bank/slice/深度、时延H和配置。
- 输入/输出坐标、任务ID、dtype、每块slot/owner、rowmask、释放沿；外壳入/出/峰值及事务引用。
- 真实MEM写使能、bank/leaf/address、字节掩码和数据；Read回读；SRF consume/collision/invalid_consume。
- 首输入、首P、最后P、源池空、外壳空、最后commit、存储任务完成；消费者测试另记VXM完成。
- 期望/实际/首分歧沿、PASS/FAIL/未测/受限、结果路径和重跑入口。新运行编号不覆盖旧证据。

### 2.1 旧测试如何迁移

原248项RTL、105项固定CModel共同功能、10项周期差分逐项建立映射表：原ID、旧合同、当前归属、是否保留有效口周期、现行用例、结果及原因。

- 保留ROW raw/API、ALL/consume、向量/map及其有效周期；BLOCK8输入与独立广播已授权删除，旧正例留档、新增明确拒绝测试，不将拆分模拟称为兼容。
- 旧逐行C814的固定16槽内部排程被主架构替换。保留旧fixture作为旧baseline证据；迁移矩阵、B矩阵非identity映射/反转和数值golden到新指令序列，显式记录排程变化。不得通过改旧expected把新旧差异抹掉。
- CModel不共有的新排程、FP32宽P或内部槽布局用独立坐标oracle，不伪造CModel周期对等。
- 历史具名FP16用例留存；新typed入口验拒绝，旧无类型16-bit传输仍逐位兼容，不能因位模式看起来像FP16而拒绝。
- 旧10项差分不能笼统标“全部继续通过”：保留合同的项必须逐拍通过，已批准替换内部排程的项单列重排证据。

### 3.1 量化事件对照

每矩阵检查：
1. 接受输入的有效元素数等于N²；宽P有效元素总数相同且坐标为Y[c,r]=X[r,c]。
2. MEM有效提交字节总数等于N²×元素字节数；重复/越界地址按布局规则拒绝，填充字节另计。
3. 实际Read回读逐位一致，未读取矩阵区域不被下一任务覆盖。
4. 源池/外壳/命令/写事务分别drain；消费者完成另记，不把固定H后的推测当commit。
5. 每个“满速”结论写明入口II、接收者能力、真实MEM命令数量和观测区间；无持续积压斜率才可称稳态成立。

1. **先M01**：冻结真实MEM服务窗口、落盘/读回布局和外壳容量；这决定10槽何时可以释放，不先写理想sink当验收。

3. 扩至三档和连续32/100矩阵，再接M06/M07真实FU；底座受限项不得隐去。
4. 稳定接口后执行P01/P02快综；功能和硬件账收口后完成P03/P04。任务归属见主spec的SXM-01～05。
